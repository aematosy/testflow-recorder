# Security

## Reporting a security issue

Do not disclose suspected security vulnerabilities in a public GitHub issue.

Use a private communication channel with the project maintainer.

## Safe testing

TestFlow Recorder should be used only on systems and applications you are authorized to test.

## Credentials

Do not store real production credentials in public recordings, screenshots, issues, or GitHub attachments.

## Browser permissions

Chrome permissions are requested only to support recorder, inspection, replay, navigation, evidence, and related QA functionality.

Incognito access is explicitly controlled by the user through Chrome.

## Source code

This public repository is a documentation repository.

The proprietary TestFlow Recorder implementation is not published here.
