# Support

## Before reporting an issue

Please include:

- TestFlow Recorder version;
- Chrome version;
- operating system;
- target page type;
- exact reproduction steps;
- expected result;
- actual result;
- sanitized screenshot or exported flow when safe.

## Good issue example

**Title**

`SPY cannot resolve locator for external social link`

**Steps**

1. Open the application.
2. Start Element Inspector.
3. Hover over the LinkedIn icon.
4. Select the element.

**Expected**

A unique locator is proposed.

**Actual**

No unique locator is resolved.

## Do not attach

- production passwords;
- access tokens;
- private customer data;
- sensitive screenshots;
- proprietary application source code.
