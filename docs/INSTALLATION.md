# Installation Guide

## Chrome Web Store

The recommended installation method is the official Chrome Web Store listing.

1. Open the TestFlow Recorder listing.
2. Select **Add to Chrome**.
3. Confirm the requested permissions.
4. Pin TestFlow Recorder to the toolbar.

## Incognito execution

Chrome does not allow extensions to enable Incognito access by themselves.

To allow isolated Incognito execution:

1. Open `chrome://extensions`.
2. Open **TestFlow Recorder → Details**.
3. Enable **Allow in Incognito**.

This setting is controlled by Chrome and the user.

## Local/manual installation

Manual installation is intended only for testing or controlled QA environments.

1. Download the approved distribution package.
2. Extract it locally.
3. Open `chrome://extensions`.
4. Enable **Developer mode**.
5. Select **Load unpacked**.
6. Choose the extracted extension directory.

## Updating

Chrome Web Store installations receive updates through Chrome's extension update mechanism.

For manual installations, replace the unpacked package with the newer approved version.
